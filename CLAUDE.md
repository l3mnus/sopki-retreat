# Sopki Retreat — сайт-портфолио

## О проекте
Одностраничный (one-page) премиальный сайт-портфолио для вымышленного бутик-отеля
«Sopki Retreat». Второй проект в портфолио, после сайта-визитки автосервиса «Гараж 51».

## Позиционирование
Камерный бутик-отель (5–15 номеров) на Кольском полуострове (Хибины / сопки
Мурманской области). Главный акцент — охота за северным сиянием (aurora hunting).
Дополнительные услуги: баня/спа, снегоходы/хайкинг, трансфер из аэропорта.

## Стиль
- Premium dark — тёмная палитра
- Крупная типографика, антиква (serif) в заголовках
- Много воздуха (whitespace)
- Видео-фон на первом экране (Hero)
- Референсы стиля: сайт кофейни Emberline, сайт ресторана Chop BBQ

## Технический стек
- Чистые HTML/CSS/JS, без фреймворков — как и в первом проекте (auto-service)
- Шрифты — локально, без CDN (см. как было на сайте 1)
- Изображения — только WebP, оптимизированы через Squoosh (squoosh.app),
  источники — только бесплатные стоки (Unsplash, Pexels, Pixabay), без чужих
  фото из произвольных сайтов
- Видео — MP4 (H.264) + WebM, короткий зацикленный ролик (5–15 сек),
  сжатое через HandBrake

## Структура блоков сайта (one-page, сверху вниз)
1. Hero — видео-фон, название, слоган, кнопка «Забронировать»
2. О ретрите — позиционирование, охота за сиянием, атмосфера уединения
3. Номера (Rooms) — карточки: фото, описание, цена
4. Демо-календарь бронирования — визуальный, без бэкенда, занятые даты
   захардкожены в JS (см. раздел ниже)
5. Услуги / аменити — баня/спа, снегоходы/хайкинг, трансфер из аэропорта
6. Галерея
7. Как добраться / локация — карта, логистика
8. Контакты / footer

## Демо-календарь бронирования — важно
Это НЕ настоящая система бронирования. Реальная занятость номеров требует
бэкенда и базы данных, чего в этом проекте нет (чистый HTML/CSS/JS,
хостинг на GitHub Pages, без сервера). Календарь должен визуально работать
как настоящий (выбор дат, подсветка занятых дней), но данные о занятости —
статичный массив в JS-файле, без реальной логики бронирования и без
реальной отправки заявки на сервер.

## Общие правила (как в первом проекте)
- Mobile-first
- Контраст текста соответствует WCAG (особенно важно на тёмном фоне)
- Safe area для iPhone
- Минифицированный CSS в финальной версии
- Форма (если будет) — с валидацией и защитой от ботов, реальная отправка —
  заглушка
- Никогда не использовать чужие фото без лицензии — только Unsplash /
  Pexels / Pixabay, все изображения проходят через Squoosh и попадают в
  проект в формате WebP
